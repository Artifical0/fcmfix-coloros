# FCMFix ColorOS 53-coloros-13-rc4

测试版。包名与签名不变，versionCode 75，可直接覆盖安装，安装后请重启手机。

LSPosed 作用域请**同时勾选“系统框架”和“电池（`com.oplus.battery`）”**。

## 修正：重启后的第一分钟不再漏推送

以前系统框架在首次解锁后要再等 1 分钟才开始放行 FCM。手机重启期间积压的消息，往往在 GMS 重新连上后的这一分钟内集中送达；
目标应用如果已被划掉后台（处于停止状态），这些消息就会被系统丢弃。现在解锁并读取配置后立即生效。

## 新图标

启动器图标改为 ColorOS 风格的蓝色渐变矢量图标，铃铛与对勾都在自适应图标的安全区内，圆形和圆角方形桌面下都不会贴边；
单色主题图标使用同一图形。安装包同时去掉了用不到的旧版 PNG 图标。

## 界面

- 应用列表改为在后台加载，打开 FCMFix 时不再卡顿；读取完成前显示加载进度；
- 缺少作用域时，点击模块状态即可向 LSPosed 申请添加，在弹出的通知中确认后重启手机；
- 移除早已停用的“目标无响应时代发提示通知”选项及相关代码（README 中的说明一并删除）。

## 包含的 53-coloros-13-rc3 改动

- 电池作用域中的 Hook 从此版本起真正生效（电池组件运行在与 Athena 共用的 `com.oplus.athena` 进程中，以前的版本因此从未加载）。
- Hook 状态、模块 API 101 显示、MIUI / HyperOS 代码移除、`collect-report.sh` 新增 Doze 白名单和睡眠待机优化两栏等 rc1 / rc2 改动。

## 测试重点

1. 新图标在桌面、最近任务、LSPosed 模块列表和单色主题图标下显示正常；
2. 打开 FCMFix 时界面立即出现，应用列表加载完成后已允许的应用排在最前；
3. 重启测试：关机，让别人给一个已划掉后台的应用发消息，开机解锁后这条消息能及时收到；
4. Hook 状态显示“电池：4 项生效”，电池设置、耗电统计等界面正常，没有异常耗电；
5. 推送收发与 53-coloros-12.1 一致，尤其是熄屏过夜后。
