# FCMFix ColorOS 13.0-rc7

测试版。包名与签名不变，versionCode 78，可直接覆盖安装，安装后请重启手机。

LSPosed 作用域请**同时勾选“系统框架”和“电池（`com.oplus.battery`）”**。

这一版根据 rc6 的实测报告改进自查：重新设计页面，区分“重连”和真正的“断线”，时间线和模块日志保留得更久。

## 自查页面重新设计

- 顶部固定显示结论：一切正常时显示 FCM 连接状态和持续时间，有问题时显示需要处理的项数和第一项问题；
- 内容分为三页，不再挤在一页：
  - **概览**：模块、Google 服务、系统信息，按分组放在卡片里；
  - **应用**：放行的应用带图标，“需要注意”和“正常”分开，正常的应用只占一行（最近推送、次数、运行状态）；
  - **时间线**：按日期分组，每条事件一行，FCM 断线红色、重连黄色、恢复绿色、网络切换蓝色；可关闭“显示推送记录”只看连接和系统事件。

## FCM 连接：区分重连和断线

rc6 只要换了一条连接就记一次“断开”，网络切换或亮灭屏时 GMS 正常换连接也会算进去，次数看着吓人。现在分为：

- **重连**：两次采样之间旧连接被新连接取代，中间不影响推送；
- **断线**：某次采样时一条连接也没有，恢复时记录“恢复连接”和断线时长（按采样估计）。

自查显示“开机以来重连 N 次，断线 M 次（最长约 X）”；当前没有连接时显示已经断线多久。

## 保留更久

- 时间线：连接与系统事件最多 300 条，推送记录单独最多 150 条，频繁的聊天推送不会再把夜间的连接记录挤掉；
- 模块日志：系统框架和电池进程各保留最近 1000 条（原 400 条），导出时压缩传输；
- 复制结果和导出报告中的时间线每条一行（rc6 中最新的 40 条被连成了一行）。

## 其他

- 自动放行不再包含系统包（UID 小于 10000，如“Android 系统”），主界面也不再给它标“包含 FCM”；自查的应用列表中不再显示系统包。
  以前手动勾选过的仍保持勾选，可在列表中取消，放行与否都不影响推送。

## 包含的 13.0-rc5 / rc6 改动

自动放行包含 FCM 的应用、自查与导出报告、状态卡片、列表显示最近推送、深色模式、FCM 连接检测、事件时间线、模块日志随报告导出。

## 测试重点

1. 自查页三页切换正常，浅色和深色模式下显示清楚；
2. 概览顶部显示 FCM 连接状态；应用页图标、分组和点击打开应用设置正常；
3. 切换 Wi‑Fi / 移动数据后，时间线记录“FCM 重连”而不是断线；关闭网络一两分钟再打开，记录“FCM 断线”和“FCM 恢复连接（断线约 X）”；
4. 时间线关闭“显示推送记录”后只剩连接和系统事件；
5. 有 Root 时导出完整报告，末尾的时间线每条一行，两段模块日志完整；
6. 推送收发与 rc6 一致，没有异常耗电。
