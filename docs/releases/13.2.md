# FCMFix ColorOS 13.2

正式版。包名与签名不变，versionCode 83，可从 13.0 或任一 13.1 测试版直接覆盖安装，安装后请重启手机。

LSPosed 作用域请**同时勾选“系统框架”和“电池（`com.oplus.battery`）”**。

## 新界面

应用界面用 Jetpack Compose（Material 3）重写。底部分为三页，右上角的齿轮进入设置：

- **状态**：原来的自查升为首页。顶部是结论，“一切正常”或“有 N 项需要处理”及第一项问题；下面逐项检查模块、作用域、
  系统框架和电池的 Hook、配置同步、FCM 连接，以及 GMS 的联网策略、待机分组和 Doze 白名单。“复制结果”和“导出完整报告”在页面底部；
- **应用**：自动放行开关、搜索，以及“全部 / 包含 FCM / 已放行 / 需要注意”筛选。通知被关闭、受限待机分组等问题直接标在列表中，
  不用再到自查页里找。点开应用可以看到通知状态、开机以来的推送次数和进程状态，跳转到系统设置，或导出附带它的日志的报告。
  放行改用每行右侧的开关，点击应用本身不再切换放行；
- **时间线**：FCM 连接与断线、网络切换、亮灭屏和深度 Doze、推送，按日期分组，可以按类型筛选；
- **设置**：原来在右上角菜单中的“阻止应用停止时自动清除通知”“允许唤醒被冰箱冻结的应用”，以及“放行所有包含 FCM 的应用”
  （原“全选包含 FCM 的应用”，现在会先确认）。

界面跟随系统深色模式，Android 12 起跟随壁纸取色，各页都可以下拉刷新。设置和放行列表沿用原来的配置，升级后不用重新勾选。

## 安装包从 7.5 MB 降到 2.8 MB

此前的 Release 没有压缩代码：APK 7.5 MB，其中 7 MB 是代码，LSPosed 会把它整个载入系统框架和电池进程。
现在用 R8 去掉依赖库中用不到的部分。Hook 部分的代码保持原样，不改名、不删除，只压缩界面和依赖库。

## 包含的 13.1 测试版改动

13.1-rc1 ~ rc3 没有发布正式版，这些改动都包含在 13.2 中：

- **ColorOS 16 适配**（[#4](https://github.com/ByteJuno/fcmfix-coloros/issues/4)、
  [#5](https://github.com/ByteJuno/fcmfix-coloros/issues/5)、[#7](https://github.com/ByteJuno/fcmfix-coloros/issues/7)）：
  - 深度睡眠联网白名单改在 ColorOS 16 和 17 共用的 `OAppNetControlManager.networkDisableWhiteList` 中补入 GMS；
  - 深度睡眠恢复后强制停止 GMS 的拦截同时处理 ColorOS 16 的 `requestSceneAction`；
  - 固件中本来就没有的限制（弱信号联网限制、只拦截 Activity 的可疑组件名单）显示“不适用”，不再算作失配。
    只有识别出已核对的固件结构时才这样显示，结构不同时仍报告失配；
- **FCM 连接识别“假连接”**：连接还在，但发出的数据连续重传没有回应，或累计 30 分钟（不计休眠时间）没有收到任何数据时，
  显示“TCP 连接还在，但……”，时间线记一条“FCM 无响应”。常见原因是本机代理的 TUN 在切换网络后断开
  （[#6](https://github.com/ByteJuno/fcmfix-coloros/issues/6)），遇到时开关一次 Wi‑Fi 或飞行模式即可恢复；
- **认出走 443 端口的 FCM 连接**：5228–5230 端口被封时 GMS 会改连 `mtalk.google.com` 的 443 端口，以前会被误报为断线；
- FCM 连接后面注明所在网络（Wi‑Fi / 移动数据），不在当前默认网络上时标出；
- 自动放行的应用关闭了通知，只作提示，不再算作需要处理的问题；
- **导出报告**：新增“GMS 的 FCM 连接”一节；修正在终端中用 `su` 运行并写入 `/sdcard` 时 `pm` / `settings` / `am` 全部报
  “Failed transaction”。

逐项说明见 [13.1-rc1](https://github.com/ByteJuno/fcmfix-coloros/releases/tag/v13.1-rc1)、
[13.1-rc2](https://github.com/ByteJuno/fcmfix-coloros/releases/tag/v13.1-rc2)、
