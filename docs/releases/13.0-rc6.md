# FCMFix ColorOS 13.0-rc6

测试版。包名与签名不变，versionCode 77，可直接覆盖安装，安装后请重启手机。

LSPosed 作用域请**同时勾选“系统框架”和“电池（`com.oplus.battery`）”**。

这一版专门为排查“FCM 显示已连接却收不到推送、过一会儿又好了”这类时好时坏的问题而改进自查。

## 自查：FCM 连接检测

系统框架每分钟查看一次 GMS 与 FCM 服务器（5228–5230 端口）之间的 TCP 连接，自查页新增“FCM 连接（系统框架检测）”：

- 已连接时显示服务器地址、这条连接已持续多久、开机以来断开过几次；
- 没有连接或一直卡在“正在连接”时会提示，这通常是网络或代理的问题。

FCM Diagnostics 里的连接时长有时一直显示 0，这一项可以作为准确的参考。检测不需要 Root，使用不会唤醒手机的定时器，熄屏休眠时不额外耗电。

## 自查：最近事件时间线

自查页末尾新增“最近事件”，按时间记录开机以来的：

- FCM 连接建立、断开（以及断开前最后一次确认在线的时间）；
- 熄屏、亮屏，进入和退出深度 Doze；
- 网络切换（Wi‑Fi、移动数据、VPN、断网）；
- 每次收到推送。

推送没来时打开自查，就能看出断开前后是否刚熄屏、进入 Doze 或切换了网络。

## 导出完整报告

- 报告末尾附上自查结果（含时间线），以及系统框架和电池进程中模块自己保留的最近 400 条日志。有些机型的系统日志只能保留几分钟，
  开机时的 Hook 结果和夜间的记录以前总是被冲掉，现在不受影响；
- 内置脚本更新：修正联网策略误报“查询失败”、模块版本下多出的 `Broken pipe`；列出 17.0.0.102 起防火墙规则所在的
  `oplus_fw_INPUT` / `oplus_fw_OUTPUT` / `fw_OUTPUT_oplus_dns` 子链；日志一栏只保留模块日志，不再被系统界面日志淹没。

## 权限

新增 `ACCESS_NETWORK_STATE`（查看网络连接，安装时自动授予，不能联网），用于时间线记录网络切换。APK 仍不申请联网权限。

## 包含的 13.0-rc5 改动

自动放行包含 FCM 的应用、自查与导出报告、状态卡片、列表显示最近推送、深色模式、新版本号格式。

## 测试重点

1. 自查中“FCM 连接”显示已连接和持续时间，与 FCM Diagnostics 的连接状态一致；
2. 熄屏放置一段时间后打开自查，“最近事件”里能看到熄屏、深度 Doze、网络变化，收到推送时有“推送 → 包名”；
3. 切换 Wi‑Fi / 移动数据、开关代理，时间线记录网络变化，FCM 连接如有重建会记录断开和重新连接；
4. 有 Root 时导出完整报告，末尾有“自查结果”和两段“FCMFix 模块日志”；
5. 推送收发与 rc5 一致，没有异常耗电。
