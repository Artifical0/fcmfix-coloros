# FCMFix ColorOS 13.0

正式版。包名与签名不变，versionCode 79，可从 53-coloros-12.1 或任一测试版直接覆盖安装，安装后请重启手机。

LSPosed 作用域请**同时勾选“系统框架”和“电池（`com.oplus.battery`）”**。

## 新的版本号

从这一版起使用独立的版本号：正式版 `13.0`，测试版 `13.0-rcN`，GitHub tag 为 `v13.0`。此前的版本号形如 `53-coloros-12.1`，
其中 53 是上游 fcmfix 的版本。模块仍基于上游 fcmfix 53，旧版本的 tag 和下载不受影响。

## 修正

- **电池作用域中的 Hook 此前从未生效。** 电池组件运行在与常驻 Athena 共用的 `com.oplus.athena` 进程中，开机时由 Athena 先启动，
  以前的版本因此从未在电池组件中挂上 Hook，推送正常靠的是系统框架中的兜底。现在电池组件中的 4 项 Hook 都会生效：
  不再对 GMS、Play 商店等写入“禁止全部联网”，清除 Google 受限广播中的受限标记，在电池组件声明 `IgnoreGmsUserSet` 时忽略旧的
  “用户改过 Google 联网”标记，深度睡眠断网白名单中加入 GMS。
- **重启后的第一分钟不再漏推送。** 以前首次解锁后要再等 1 分钟才开始放行 FCM，重启期间积压的消息若在这一分钟内送达已划掉后台的应用，
  会被系统丢弃。现在解锁并读取配置后立即生效。

## 新功能：自动放行包含 FCM 的应用

应用列表顶部新增开关，默认关闭。开启后所有包含 FCM 接收组件的应用都会被放行，之后新安装的应用也会自动放行；
在列表中取消勾选某个应用即可排除它。手动勾选的应用照常放行。系统包（UID 小于 10000）不会被自动放行。

## 新功能：自查与导出报告

点击顶部的状态卡片，或菜单中的“自查与导出报告”进入，不需要 Root。页面分为三页：

- **概览**：模块是否激活、作用域、系统框架和电池的 Hook 是否生效；GMS 的 ColorOS 联网策略、待机分组、Doze 白名单；
  **FCM 连接**（系统框架每分钟检测一次 GMS 与 FCM 服务器之间的 TCP 连接），显示连接持续时间、开机以来重连和断线的次数；
- **应用**：每个放行应用的通知开关、被关闭的通知类别、待机分组、进程状态，以及开机以来最近一次收到推送的时间和次数。
  收到了推送却没有通知，问题通常在应用这一侧；
- **时间线**：FCM 断线、重连、恢复，熄屏亮屏，深度 Doze，网络切换（含 VPN）和每次推送，按日期分组。
  推送没来时打开这里，就能看出当时是否刚熄屏、进入 Doze 或切换了网络。

“重连”指旧连接被新连接取代，不影响推送；“断线”指某次检测时一条连接也没有，恢复时会记录断线时长。
FCM 一直连不上通常是网络、DNS 或代理的问题，FCMFix 无法解决。

结果可一键复制。有 Root 时“导出完整报告”会运行内置的 `collect-report.sh`，可附带某个应用的通知状态和系统日志，
报告末尾还会附上自查结果和模块自己保留的最近日志（系统框架和电池进程各 1000 条），不会被系统日志冲掉。

## 界面

- 顶部的状态卡片：正常时显示“一切正常”和各作用域生效的 Hook 数，有问题时显示第一项问题；缺少作用域时点击即可向 LSPosed 申请；
- 应用列表在后台加载，已放行的应用显示最近一次收到推送的时间；
- 支持深色模式；新的蓝色矢量图标，支持单色主题图标。

## 其他

- 移除不会在 ColorOS 上生效的 MIUI / HyperOS 适配、需要 GMS 作用域的旧重连功能和“目标无响应时代发提示通知”选项；
- 系统框架中的 ColorOS Hook 按功能拆分，每组 Hook 一项都没挂上时记为失配，不会被当成生效；
- `collect-report.sh` 新增 Doze 白名单、睡眠待机优化记录、17.0.0.102 起的防火墙子链，可附带一个或多个应用包名；
- 新增 `ACCESS_NETWORK_STATE`（查看网络连接，安装时自动授予），用于时间线记录网络切换。APK 仍不申请联网权限；
- 更新界面依赖库和构建工具。

## 说明

- 在 ColorOS 17 国行上，流量管理的联网策略里 Google 应用可能仍显示为禁止联网，但实际不会断网；以自查中的 FCM 连接为准。
- FCMFix 不能让 GMS 连上 FCM 服务器，DNS 污染或端口封锁需要自行解决。判断方法见
  [如何提交问题与日志](https://github.com/ByteJuno/fcmfix-coloros/blob/master/docs/report-issue.md)。
